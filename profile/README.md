# CleverBird

CleverBird is a connected software-development platform: plan, code, review, test and ship from one account and one shared project, so your work keeps its context as it moves between tools.

Founded by **Aaditya Pandey** and **Aniket Shankar**. Official website: **[cleverbird.co](https://cleverbird.co)**

### Being built now

| Tool | What it does | Status |
| --- | --- | --- |
| SwiftBot | An AI helper that writes, explains and fixes code with you | Final stages |
| NestIDE | A code editor that runs in your browser, with an AI helper built in | Final stages |
| FlockManage | Plan projects and keep track of tasks with your team | In development |
| NestLearn | Learn to code with short lessons, quizzes and projects | In development |

More tools are planned. See the [roadmap](https://cleverbird.co/roadmap) and [all products](https://cleverbird.co/products).
